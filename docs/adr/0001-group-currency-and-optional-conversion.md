# Keep group accounts in one currency with optional conversion

The owner chose a single group currency for recorded debts, with optional foreign-currency expenses and a personal display currency. Preserve the original expense amount and the rate used so exchange-rate changes cannot rewrite historical debts; display conversion does not change what members owe. This supports international trips without introducing separate debt balances in every currency.

Foreign-currency repayments follow the same saved-conversion rule and reduce debt by their confirmed group-currency equivalent. Suggest rates for the day an amount is entered, permit manual overrides and fallback entry, and fix the group currency after the first financial record.
