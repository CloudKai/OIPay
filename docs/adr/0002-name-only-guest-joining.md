# Allow guest membership through a shared invitation link

The owner chose reusable group invitation links with name-only joining so invited people can participate without signing up. Group creators still require accounts, while guests are recognised in the same browser and can optionally attach an account for recovery and other devices. A name is a display label rather than proof of identity; replacing the existing email-bound invitation requirement therefore needs separate guest credentials and permission checks.

If a guest loses access before linking an account, the owner may issue a private recovery link for the same membership that replaces previous guest access. Require distinguishable names within a group to reduce expense-assignment errors, while never treating a name match as identity verification.
