# SplitTogether Next.js MVP

Full-stack Splitwise-style web MVP built with:

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL
- NextAuth (email/password credentials)

## Features

- Authentication (signup + login)
- Protected routes (`/dashboard`, `/groups/[id]`)
- Group creation and membership by email
- Expense creation with equal or exact split
- Settlement recording between group members
- Net balance computation + greedy debt simplification
- Group activity feed (expenses, settlements, member adds)
- Seed data with demo users + `Bali Trip`

## Database models

- `User`
- `Group`
- `GroupMember`
- `Expense`
- `ExpenseShare`
- `Settlement`
- `ActivityLog`

## Setup

### Fast start (from repo root)

```bash
./start-web.zsh
```

This starts Postgres, prepares `web/.env`, syncs the schema, and runs the web app.

Optional:

```bash
./start-web.zsh --reset-db
```

Use `--reset-db` only when you want to wipe local data and re-seed demo data.

1. Install dependencies:

```bash
cd web
npm install
```

2. Configure env:

```bash
cp .env.example .env
# recommended for local dev and required for production:
openssl rand -base64 32
# paste output into NEXTAUTH_SECRET in .env
```

If `NEXTAUTH_SECRET` is left blank locally, the app uses a deterministic machine-specific dev secret so onboarding still works.
In production, you must set `NEXTAUTH_SECRET` to a strong random value.

3. Ensure PostgreSQL is running (from repo root, optional helper):

```bash
docker compose up -d
```

4. Generate Prisma client + run migrations:

```bash
npm run prisma:generate
npm run prisma:migrate
```

5. Seed demo data:

```bash
npm run prisma:seed
```

6. Start dev server:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Notes on business logic

- For each expense, payer is credited with full total.
- Each participant is debited by their share.
- Net balance = `paid - owed`.
- Settlements are applied as opposite entries:
  - payer gets credited
  - receiver gets debited
- Simplified debts are generated by greedy matching debtors to creditors.
- Only members of a group can be used in expenses or settlements.
